## 個人簡介 <img src="https://media.giphy.com/media/mGcNjsfWAjY5AEZNw6/giphy.gif" width="50">

我是一名專注於 **Minecraft 社群** 的創作者。憑藉對 **JVM 內部機制及 Minecraft 伺服器核心 (NMS)** 的深入理解，我專注於解決高併發環境下的效能瓶頸，並撰寫專業技術文檔與教學方案。

我的主要專長領域：

* **伺服器架構：** 基於 Folia / Paper 的高效能叢集設計與負載平衡。
* **影片製作：** 製作入門教學影片與深度解析 Minecraft 遊戲機制及社群生態。
* **技術文檔：** 長期撰寫 Markdown 教學文檔與教程。
* **開源貢獻：** 積極參與開源專案，累積實戰經驗。

> *「我曾在遊戲中花了一週時間建造一座城堡，但因一個小失誤而全毀。我曾憤怒，但最終明白——真正重要的不是城堡，而是我學會建造它的那些夜晚。」*
